# Nuvio AI Subtitles Provider
Thin contract-shell APK for NuvioTV (`com.nuvio.tv.provider.subtitles`).
Its Messenger service negotiates `SUBTITLE_CUES_V1@1`; there is no launcher activity.
The real subtitle engine lands later; this preview stores no credentials and has no network code.
Signed with the Nuvio dev key for host-side certificate verification before binding.
