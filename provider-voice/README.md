# Nuvio AI Voice Provider
Thin contract-shell APK for NuvioTV (`com.nuvio.tv.provider.voice`).
Its Messenger service negotiates `DUB_ARTIFACT_V1@1`; there is no launcher activity.
The real voice engine lands later; this preview stores no credentials and has no network code.
Signed with the Nuvio dev key for host-side certificate verification before binding.
